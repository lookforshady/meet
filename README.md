# DESCRIPTION:

* Create a meeting with just one command (Python3 required)

# USAGE:

1. Open Terminal/Powershell
2. Type `meet` and press Enter

# INSTALLATION

Clone this repository using `git clone 'https://github.com/lookforshady/meet.git'`
(or)
Download this folder manually (run `chmod +x install.sh` on Linux/MacOS)

## Linux/MacOS:

`./install.sh`

## Windows:

`./install.ps1`
